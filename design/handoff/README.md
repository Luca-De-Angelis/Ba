# Consegne di Claude Design

Una cartella per task: `001/`, `002/`, …

Ogni cartella contiene:

1. Gli screenshot di ogni schermata o stato, con nomi parlanti (`palco-microfono-spento.png`).
2. `changelog.md`: tabella con documento, sezione, prima, dopo, motivo in una riga.
3. `tokens.diff.md`: solo le righe nuove o cambiate di `tokens.dart`.
4. Per il task 002, anche `suono-e-vibrazione.md`: evento, segnale, motivo.

Niente file HTML interi: quelli aggiornati vanno in `design/system/`.
